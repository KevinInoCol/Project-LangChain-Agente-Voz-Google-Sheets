## Este proyecto puede trabajar con
Python 3.12

## Crea un Virtual Environment:
conda create -n LangChain-Agente-Voz-Sheets python=3.12

## Activa tu Virtual Environment:
conda activate LangChain-Agente-Voz-Sheets

## Instalamos dependencias
pip install -r requirements.txt
